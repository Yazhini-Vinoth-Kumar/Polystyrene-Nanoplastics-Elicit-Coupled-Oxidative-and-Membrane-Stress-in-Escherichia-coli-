# Source data for “Polystyrene Nanoplastics Elicit Coupled Oxidative and Membrane Stress in Escherichia coli”

This repository contains the source data and analysis files used to generate the figures in the main manuscript and Supporting Information.

The data are organised by experimental technique:

01_Growth
Contains source data for Figure 1 and Figures S1 to S2, including growth-rate data, growth curves, raw growth files, derivative data, and the analysis notebook used for growth-phase determination.

02_Flow_Cytometry
Contains source data for Figure 2, intracellular ROS, and Figure 3, membrane lipid oxidation.

03_AFM
Contains source data for Figures 4 to 7 and Figures S3 to S13, including force-indentation curves, cross-sectional height profiles, bacterial spring constant, apparent Young’s modulus, representative fitting data, PLL substrate measurements, and AFM topography images.

04_STEM
Contains representative STEM images for Figure 8 and the quantitative dark-spot data used for Figure 9 and Figure S12.

Numerical source data are provided mainly as Excel workbooks. Representative images and analysis files are included where relevant. Large AFM files are stored using Git LFS.

The data should be interpreted together with the methods, figure captions, and analysis procedures described in the manuscript and Supporting Information.
